# Bundled signature font

`KaushanScript-Regular.ttf` is an unmodified copy of Kaushan Script from the
official Google Fonts repository. Copyright notices and the SIL Open Font
License 1.1 are preserved in `OFL-KaushanScript.txt` and in the font metadata.
The font is the default cursive name face for the split-column appearance.

installed Arial font unless overridden through `--text-font`.
